# Federal Institute of Science And Technology (FISAT) - Web Portal

A modern, responsive, and high-fidelity web portal for **FISAT (Federal Institute of Science And Technology)**, Hormis Nagar, Mookkannoor, Angamaly, Kerala. Built with pure HTML5, CSS3, and modern JavaScript, capturing official institutional information from [https://fisat.ac.in/](https://fisat.ac.in/).

## 🚀 How to Run the Website

### Option 1: Direct Browser Opening
Simply double-click [`index.html`](file:///C:/Users/Hp/.gemini/antigravity/scratch/fisat-website/index.html) in Windows File Explorer or open it with any web browser (Chrome, Edge, Firefox).

### Option 2: Local HTTP Server
From the terminal, inside `C:\Users\Hp\.gemini\antigravity\scratch\fisat-website`:
```powershell
# Using Python
python -m http.server 3000

# Or using Node.js / npx
npx serve .
```
Then visit `http://localhost:3000` in your browser.

## 🛠️ Interactive Features Built In

1. **Dark & Light Mode Switcher**: Toggles theme seamlessly with persistent memory.
2. **Interactive Program Detail Modal**: Click "Curriculum & Details" on any branch to view duration, intake, eligibility, core subjects, and career avenues.
3. **Interactive Fee & Eligibility Estimator**: Select quota (Govt. Merit / Management / NRI) and percentage to preview tuition and criteria.
4. **Quick Site Search Modal**: Live keyword search across departments, facilities, leadership, and fests.
5. **Admission Enquiry Modal & Form**: Fully validated with responsive toast feedback notifications.
6. **Animated Counter & Recruiters Ticker**: Dynamic stats counters and marquee scrolling of corporate logos.
